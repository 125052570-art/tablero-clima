# Dashboard Interactivo de Bitcoin (API CoinGecko)
**Materia:** Herramientas de Visualización (IDIA223-4)  
**Actividad:** EP.03.01 - Evidencia de Producto

## Descripción
Transformación del análisis de datos de la API pública de CoinGecko hacia un tablero interactivo desarrollado con **Streamlit**, utilizando `pandas` para el procesamiento y `matplotlib` para la visualización bajo la paleta institucional del curso.
